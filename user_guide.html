1. Global Navigation & Top Header Bar

The top header bar is persistent across all authorized pages and contains vital multi-branch controls, instant booking actions, and account settings.

Control / Button Type Functionality & Operation
Sidebar Toggle [▤] Icon Button Collapses or expands the navigation sidebar to maximize workspace area on laptops and POS tablets. Remembers user preference in local storage.
Branch Switcher Dropdown Select Switches the active branch view (e.g. Downtown Branch vs. Uptown Spa). All data, calendars, inventory, and staff filters instantly adapt to the chosen branch.
Date Chip Status Indicator Displays the current operational calendar date formatted for the salon's timezone.
Global Search Bar Input Field Searches bookings, invoices, customers by mobile number or name with live instant results.
+ New Booking Primary Action Opens the global fast-booking modal from anywhere in the app to book an appointment in under 15 seconds without leaving your current work.
Plan Badge Status Badge Displays your salon's active subscription tier (e.g. Growth, Basic, or Enterprise). Clicking navigates to billing settings.
Notifications Bell [🔔] Dropdown Panel Shows unread alerts: upcoming appointments, stock depletion warnings, and support updates with red badge counter.
User Avatar & Menu Profile Dropdown Opens quick profile options: Profile, Schedule, Settings, Support, and Logout.

2. Dashboard Overview (`dashboard.html`)

The operational cockpit showing real-time salon performance, walk-in traffic, and schedule status.

Dashboard Element What It Shows & Action
Today's Revenue Metric Total money collected today across cash, card, and UPI. Clicking links to the detailed revenue breakdown screen (`todays-revenue.html`).
Appointments Metric Total scheduled slots vs completed appointments. Clicking links to `upcoming-appointments.html`.
Walk-ins & Clients Counter of unscheduled walk-in customers and new customer registrations.
Today's Schedule Table Live list of appointments today. Contains quick action buttons on each row:
• Check-In: Marks client as arrived in salon.
• Checkout: Directly sends appointment to POS terminal.
• Cancel: Releases staff slot and updates booking status.

3. Bookings & Appointments Engine

Central calendar and scheduling suite for client appointments, stylist assignments, and status tracking.

Primary Pages

  • `bookings.html`: Master calendar view (Day, Week, Month) with stylist columns.
  • `upcoming-appointments.html`: Filterable list of confirmed upcoming slots.
  • `completed-appointments.html`: Historical archive of finished services.
  • `no-shows-cancellations.html`: Record of missed appointments for cancellation policy analysis.

Key Buttons & Modal Operations in Bookings

Button / Action Description & Operation
New Booking Modal 1. Customer Phone: Auto-completes existing customer profile or prompts to add new client.
2. Service Picker: Choose haircut, facial, coloring with automatic duration calculation.
3. Staff Member: Select available stylist or choose "Any Available".
4. Date & Time Slot: Visual slot picker displaying free vs busy time blocks.
5. Confirm Booking: Saves appointment, updates stylist schedule, and triggers automated SMS/WhatsApp confirmation.
Reschedule Opens pre-filled booking modal to choose a new time or assign a different stylist without deleting client history.
Cancel Booking Prompts for cancellation reason and instantly frees up stylist calendar.
Calendar View Filters Buttons to switch between Day, Week, and Month grid views, plus a filter by Stylist.

4. Customers Directory (`customers.html`)

Complete CRM database storing client visit histories, formulas, preferences, and spending patterns.

Button / Action Operation
+ Add Customer Opens registration drawer to record Name, Mobile, Email, Gender, Birthday/Anniversary (for auto-discounts), and Notes.
View Profile Card Opens client 360° overview: past visits, favorite staff, membership status, total lifetime value (LTV), and notes.
Quick Book Button Launches the booking modal with client information already populated.
Export CSV Downloads the filtered client database for external campaign reporting.

5. Staff Roster & Shift Scheduling

Manage salon professionals, service specialties, work shifts, breaks, and commission tiers.

Screen & Buttons Functionality
`staff.html`
+ Add Staff		 Adds a new employee: Full Name, Role (Stylist, Receptionist, Manager), Phone, Base Salary, and Commission % on Services and Retail Products.
Active / Inactive Toggle Temporarily pauses stylist from receiving online bookings without deleting their past sales history.
`staff-schedule.html`
Set Shift Times		 Assigns weekly working hours (e.g., 10:00 AM – 7:00 PM), lunch breaks, and designated weekly off days.
Mark Leave Blocks specific dates on the booking engine so clients cannot book absent staff.

6. Services & Packages Setup

Define the salon menu, service categories, pricing tiers, and execution durations.

Screen & Buttons Operation
`services.html`
+ Add Service		 Creates menu items: Service Name, Category, Price (inclusive/exclusive of GST), Duration in minutes, Buffer time, and Stylist Commission rate.
`service-categories.html`
+ New Category		 Organizes services into clean tabs (e.g. Hair Care, Skin & Facials, Nails, Bridal Packages).
Pricing / Edit Modifies prices or duration across all branches or specific selected branches.

7. Point of Sale (POS) & Retail Products

High-speed billing terminal built for touchscreens and barcode scanners to process checkouts in seconds.

POS Feature Operation & Workflow
Service & Product Cart Click services from visual grid or scan retail barcode. Automatically calculates subtotal, GST, and discounts.
Assign Stylist Links individual line items to the stylist who performed the service to ensure accurate commission payroll.
Apply Discount / Coupon Allows fixed amount or percentage discount, or enters a marketing coupon code with automated limit checks.
Tender / Pay Opens payment selector supporting Split Payments:
• Cash: Displays change calculator.
• Card / POS Machine: Records card terminal auth code.
• Dynamic UPI QR: Generates QR code directly on screen for customer scanning.
Print Invoice Sends formatted receipt to 80mm or 58mm thermal receipt printers with GSTIN, salon logo, and optional UPI QR.
`products.html`
+ Add Product		 Manages salon retail inventory: Product Name, SKU, Barcode, Cost Price, Selling Price, and Low-Stock Alert threshold.
`sales-history.html` Full invoice repository allowing search by Bill #, customer name, re-printing duplicate receipts, and issuing refunds.

8. Payments & Settlement Tracking

Track payments received, pending dues, and reconciliation with payment gateway logs.

Screen & Button Functionality
`pending-payments.html`
Collect Payment		 Lists clients with outstanding balances or pay-later appointments. Clicking launches payment modal to collect partial or full balance.
Send Reminder Dispatches payment reminder with dynamic pay link via WhatsApp/SMS.
`payments-history.html` Audited financial log showing every transaction, payment mode, reference ID, cashier name, and reconciliation status.

Tools to boost repeat visits, run festive promotions, and sell recurring subscription memberships.

Marketing Module Buttons & Workflow

`coupons.html`

10. Analytics, Reports & Business Expenses

Comprehensive business intelligence to monitor salon profitability, staff commissions, and operational overheads.

Report Screen Information & Export Actions
`overview.html` Executive dashboard displaying monthly revenue trajectories, peak service hours, and client retention rates.
`reports.html` Detailed reports suite:
• Sales Report: Breakdowns by payment mode and tax collections.
• Staff Commission Report: Exact payout owed to each stylist based on services rendered.
• Inventory Consumption: Professional backbar products consumed vs retail sales.
Download CSV / PDF Exports formatted reports for your Chartered Accountant (CA) or salon accountant.
`expenses.html`
+ Add Expense		 Tracks operational expenditure: Salon rent, electricity, laundry, coffee supplies, equipment maintenance, and staff advances.

11. Salon Settings & Customization

Configure salon profile, multi-branch setup, user access control, and invoice templates.

Settings Area Controls & Configuration
`company.html` Legal business details, registered company name, address, GSTIN / Tax number, contact numbers, and currency symbol.
`settings-branding.html` Upload salon brand logo, favicon, and brand color palette applied across invoices and client portal.
Invoice Designer Suite
(`settings-invoice.html`)		 Visual drag-and-drop designer for thermal receipt templates:
• Choose paper width (80mm vs 58mm).
• Toggle custom headers, salon social handles, and WiFi passwords.
• Print dynamic UPI payment QR code at the bottom of bills.
• Customize terms, cancellation policies, and GST tax breakdowns.
`settings-hours.html` Weekly salon timing (Opening & Closing times for each day of the week, plus public holidays).
`settings-payments.html` Payment gateway configuration: Razorpay / Stripe credentials, UPI VPA handles, and EDC card machine terminal IDs.
`users.html` & `roles-permissions.html` Role-based access control (RBAC). Create roles (e.g. Receptionist, Floor Manager, Accountant) and toggle feature permissions (e.g., hide revenue reports from stylists).

12. Help, Support, Issue History & Feedback Suite

Comprehensive built-in support infrastructure providing instant self-help, technical ticketing, suggestions, and app reviews.

Support Page (`support.html`) Header Controls

Header Button Trigger / Component Operation & Workflow
User Manual Direct Link Opens this complete documentation guide and searchable FAQ knowledge base.
Report an Issue ⌵ Dropdown Menu with 2 Options:
1. Report an Issue
2. Issue History 		1. Report an Issue: Opens modal dialog to report a problem (Category, Subject, Description, and file attachment). Submits and generates a Ticket ID (`#BB-xxxxx`).

2. Issue History: Navigates directly to the dedicated issue-history.html portal.
Suggestions Modal Dialog
("Share a Suggestion")		 Opens feature request modal:
• Category: Appointments, POS & Billing, Staff, Loyalty, etc.
• Suggestion Title & Detailed Description.
• Why Would This Be Useful? (Business impact).
• Image Attachment Dropzone: Upload UI mockups/screenshots.
• Upon submission, displays a Thank-You confirmation card.
⭐ Review Modal Dialog
("Rate Your Experience")		 Opens rating modal:
• Interactive 5-Star Rating: Click stars 1 to 5 with live hover descriptions.
• Comments Textarea: Optional user feedback.
• Submit Review: Saves rating and displays confirmation card with checkmark.

Dedicated Issue History Page (`issue-history.html`)

🌐 Public Ticket Tracking System
The Issue History page is configured as an unrestricted, public dashboard (bypassing auth-guard) allowing team members to monitor support progress and collaborate with technical specialists.
Component Operation
Status Filter Tabs Tabs displaying real-time counts: All, Open, In Progress, Resolved, Closed. Clicking filters tickets instantly.
Ticket Cards List (Left Panel) Scrollable list of ticket cards showing Ticket ID, priority pill, category tag, message preview, timestamp, and message counter. Clicking any card displays its thread on the right.
Conversation Thread (Right Panel) Displays the full discussion timeline with support specialists, verified agent badges, timestamps, and attachment previews.
Reply Composer Allows the user to reply to the support team, attach screenshots, and click Send Reply to append messages in real time.
Mark Resolved / Reopen Allows closing tickets when resolved or reopening them if further assistance is required.
